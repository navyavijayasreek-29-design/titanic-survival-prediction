About the Project

This project uses Machine Learning techniques to predict whether a Titanic passenger would survive based on passenger information such as class, gender, age, family members, fare, and port of embarkation.

Python Machine Learning Pandas Scikit-learn Streamlit Titanic Dataset

Project Files

The project contains the trained Machine Learning model, Titanic dataset, analysis notebook, model comparison results, and Streamlit application.
